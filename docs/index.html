Fresh VPS · four open ports

One command. Keep the first session open.

Before installation, allow TCP 22, 2222, 80 and 443 in the provider firewall and confirm emergency console access. Then run:

curl -fsSL https://raw.githubusercontent.com/rahbanssh/rahbanssh/main/install.sh | sudo env RAHBAN_MOVE_HOST_SSH=1 bash
Do not close your current SSH session. Test the red-box management command printed by the installer in a second terminal first.

Straight answers

Before you deploy.

Is this a complete UDP VPN?

No. Rahban is an SSH TCP tunneling platform. SSH forwarding and SOCKS5 work; native full-UDP behavior is outside the current scope.

Can customers access the VPS host?

No. Panel-created Linux users live inside the SSH container. The panel does not mount the host user database or host /etc.

What happens to normal VPS SSH?

The default installation moves host administration to port 2222 and gives customer SSH port 22. The installer prints and saves the exact replacement command.

Does Rahban report credentials or charge commission?

No. The project has no creator login, backdoor, credential reporting, hidden remote access or commission mechanism.

Can I use a custom hostname?

Yes. Point the hostname to the VPS first and pass it through PANEL_PUBLIC_HOST. Traefik handles HTTPS with Let’s Encrypt.
